# Minha Primeira Variável

Este programa foi criado para testarmos a criação de variáveis.

## O que é uma variável?

Um local para guardar informações temporárias

## O que faz o Console.Write?

printa no console (terminal) textos.

## Qual é a diferença entre Console.Write e Console.WriteLine?

Console.Write printa frases onde não iram ter quebra de linha, já o Console.WriteLine printa texto onde irão ter uma quebra de linha.
